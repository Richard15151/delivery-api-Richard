🍔 Delivery API

API de delivery desenvolvida em Java com Spring Boot, responsável por
gerenciar pedidos, clientes e produtos.

------------------------------------------------------------------------

🚀 Tecnologias

-   Java
-   Spring Boot
-   Spring Web
-   Spring Data JPA
-   Banco de dados (MySQL ou H2)
-   Maven

------------------------------------------------------------------------

📦 Funcionalidades

-   Cadastro de clientes
-   Cadastro de produtos
-   Criação de pedidos
-   Listagem de pedidos
-   Atualização de status de pedidos

------------------------------------------------------------------------

▶️ Como rodar o projeto

1.  Clone o repositório: git clone
    https://github.com/Richard15151/delivery-api-Richard.git

2.  Acesse a pasta: cd delivery-api

3.  Execute o projeto: ./mvnw spring-boot:run

Ou rode pela sua IDE.

------------------------------------------------------------------------

🔗 Endpoints principais

  Método   Rota        Descrição
  -------- ----------- ----------------
  GET      /produtos   Lista produtos
  POST     /produtos   Cria produto
  GET      /clientes   Lista clientes
  POST     /clientes   Cria cliente
  GET      /pedidos    Lista pedidos
  POST     /pedidos    Cria pedido

------------------------------------------------------------------------
